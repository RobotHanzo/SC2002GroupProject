49	| Pasta | $18.00 | 2 |

51	| Salad + Pasta (combo) | $24.30 | 3 |

80	
81	Switched on at the start of a turn, it lasts for that turn and the next, and the screen shows the turns left. While it is on:
82

88	### Rules this implementation fixes where the brief leaves a choice
89	
90	- **Food choice.** Regular and VIP customers take menu entry number `customerId mod 5` (the menu has five entries: Salad 0, Burger 1, Pasta 2, Salad + Burger 3, Salad + Pasta 4), so customer 1 orders a Burger, 2 a Pasta, 3 the Salad + Burger combo, 4 the Salad + Pasta combo, 5 a Salad. The Critic ignores that rule and takes the most expensive entry. The choice is shown when the order is taken.
91	- **Price lock.** The bill is worked out when the Waiter takes the order (customer's own pricing first, then Happy Hour) and is stored in the Order; the Cashier collects that amount.
92	- **Critic reaction.** "Served more than 2 turns after the order was taken" means the serving turn minus the order turn is 3 or more. A 3-unit combo ordered on turn *n* is READY at the end of turn *n*+2 at the earliest and served on turn *n*+3, so the Critic's combo always costs the extra 10 satisfaction; with a 2-unit dish a prompt Waiter avoids it.
93	- **Order of events in a turn.** Arrival, Happy Hour choice and recovery, your Host choice, your Waiter choice, your Chef choice (so the Chef can work on an order taken this turn, and the Waiter can take the order of a customer the Host has just seated), eating and payment, then waiting and abandonment. A dish the Chef finishes this turn is READY only after the Waiter has acted, so it is served next turn at the earliest.
94	- **Eating and payment.** A customer served on turn *n* is READY_TO_PAY on turn *n*+1 and can pay on turn *n*+2. "Oldest first" means the customer who arrived first.

/**

 * that turn and the next. While active, orders taken get 20% off and customers still waiting for
 * a table or food recover 15 satisfaction at the start of the turn. It never changes an order

public class HappyHour {
    private static final int DISCOUNT_PERCENT = 20;
    private static final int RECOVERY = 15;
    private static final int DURATION = 2;

    private boolean used;
    private int remainingTurns;

    /** Switches Happy Hour on. Returns false (and changes nothing) if it was already used this game. */
    public boolean activate() {
        if (used) {
            return false;
        }
        used = true;
        remainingTurns = DURATION;
        return true;
    }

    public boolean isActive() {
        return remainingTurns > 0;
    }

    /** True until the manager switches Happy Hour on; it cannot be used a second time. */
    public boolean isAvailable() {

    }

    }
}
